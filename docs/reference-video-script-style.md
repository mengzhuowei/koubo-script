# 参考视频口播风格模型

## 样本概况

- 样本：`koubo视频.mp4`
- 时长：8 分 11 秒
- 语言：中文
- ASR：369 个时间片，语言置信度约 99.87%
- 节奏：约 3390 个可朗读字符，实测约 6.9 字/秒；时间片中位数约 9 字、1.2 秒
- 使用原则：学习结构、推进方式和语气，不复制样本题材、人物、案例、事实或原句

自动转写包含少量专有名词与同音误差，因此风格判断以整段语义、时间结构和重复修辞为准，不以个别词为准。

## 可复用的语言指纹

1. **证据先于自我介绍**：第一句话就让观众“看到”一个结果、实物或变化。
2. **判断清楚**：解释完证据立即给结论，不让观众自己猜本段重点。
3. **高频概念纠偏**：用“看起来是……严格来说不是……而是……”重设理解框架。
4. **抽象与具体交替**：机制后接案例，案例后再上升到行业规律。
5. **自然口语连接**：用“那、所以、比如、但是、你看”推进，听感像连续对话，不像条目朗读。
6. **先讲机会，再讲约束**：不止描绘收益，还补交付、预算、客户筛选和扩张节奏。
7. **对立面明确**：把“闭门造车、先扩团队、只按自己想法做”等错误动作说透，再给替代动作。
8. **强观点配条件**：表达直接，但项目生成时只能在资料支持下下强结论；没有来源就改为条件式表达。

## 项目生成规则

- 开头按优先级选择：有来源的具体结果 > 有来源的变化 > 观众正在经历的具体场景。
- 60 秒以上至少提供一个具体例子或可执行场景；90 秒以上必须出现风险、前提或边界。
- 工具教程在 45 秒以上必须包含：常见错误、概念纠偏、分步动作、检查点、可复制话术。
- 案例必须来自输入事实；没有事实时只能写成明确的假设场景。
- 目标语速按 5.5～6.5 个可朗读字符/秒预算，保留参考视频的推进感，同时给停顿和理解空间。
- 结尾顺序：方法提醒 → 现在就能做的动作 → 一句人设型 CTA。
