# AI Agent Efficiency Coach Product Design

版本：V0.1

定位：面向可配置账号人设的 AI Agent 选题、总结、口播脚本生产工作台。默认人设为“AI效率教练”。

## 1. 产品一句话

把 AI Agent 前沿信息自动整理成可信、可讲、可执行的短视频选题，并生成符合当前设置人设的抖音/小红书口播脚本。

## 2. 背景与问题

当前内容创作的主要痛点不是缺少信息，而是：

1. 信息源太分散：官方博客、框架更新、GitHub 项目、论文、社区讨论分布在不同平台。
2. 热点质量不稳定：很多内容只是营销噪音，不能直接变成有价值的视频。
3. 技术内容难转译：英文技术文章、论文、文档不容易变成普通人能听懂的中文口播。
4. 每期选题成本高：每天都要重新找资料、判断价值、组织结构、写脚本。
5. 账号定位需要稳定：作为“AI效率教练”，内容要落到效率工作流，而不是单纯报新闻。

## 3. 目标用户

### 3.1 核心用户

AI Agent / AI 工具方向的内容创作者，主要发布平台为抖音、小红书。

### 3.2 账号人设

名称：AI效率教练

人设说明：

> 我专门把复杂的 AI Agent 前沿技术，拆成普通人、内容创作者、小团队也能直接上手的效率工作流。

说明：AI效率教练是默认人设，不应写死在代码里。MVP 需要提供设置页，让用户可以修改人设名称、定位、目标受众、语气、内容边界和默认 CTA。

### 3.3 目标观众

1. AI 工具新手
2. 内容创作者、知识博主
3. 独立开发者
4. 小团队老板
5. 想用 AI 提效的职场人

## 4. 产品目标

### 4.1 MVP 目标

1. 每天从固定信息源采集 AI Agent 相关内容。
2. 自动生成候选选题和内容卡。
3. 按页面设置的人设给选题评分。
4. 一键生成抖音/小红书口播脚本。
5. 保存脚本版本和来源证据，方便后续修改和复盘。

### 4.2 非目标

MVP 阶段暂不做：

1. 多人协作。
2. 复杂权限系统。
3. 前后端分离。
4. 向量数据库。
5. 自动发布到抖音/小红书。
6. 大规模分布式爬虫。
7. 复杂数据看板。

## 5. 核心使用流程

### 5.1 每日内容生产流程

1. 用户打开首页。
2. 点击“抓取今日内容”。
3. 系统从信息源采集文章、文档、GitHub 项目、论文和社区帖子。
4. 系统清洗正文、去重、分类。
5. 系统生成内容卡，并按可讲性排序。
6. 用户进入“今日选题榜”，挑选一个选题。
7. 用户查看来源、摘要、关键事实和风险提醒。
8. 用户选择平台、时长、栏目和口播风格。
9. 系统生成脚本。
10. 用户编辑并保存最终版本。

### 5.2 选题到脚本流程

```text
原始内容 -> 清洗去重 -> 内容摘要 -> 选题聚合 -> 内容卡 -> 评分排序 -> 口播脚本
```

说明：发布素材包属于 V0.2 能力，V0.1 只保留脚本标题、正文和 CTA 的保存能力，避免第一版范围膨胀。

## 7. 内容卡设计

### 7.1 字段

```text

推荐时长
关键事实
来源链接
实操价值
风险提醒
可复制动作
推荐钩子

状态
```

## 8. 选题评分模型

总分 100 分。

| 维度 | 权重 | 说明 |
|---|---:|---|
| 新鲜度 | 20 | 是否最近发布、是否仍在讨论窗口 |
| 来源权威度 | 20 | 官方、论文、代码优先 |
| 实操价值 | 20 | 是否能转成具体工作流 |
| 观众可理解度 | 15 | 普通用户是否能听懂 |
| 反差/争议感 | 10 | 是否有可讲的误区、反常识、分歧 |
| 平台适配度 | 10 | 是否适合抖音/小红书短视频 |
| 人设匹配 | 5 | 是否符合当前设置的人设定位 |

风险扣分：

1. 来源不可靠。
2. 只有营销话术。
3. 关键事实缺少出处。
4. 技术结论过度夸张。
5. 无法转成观众可执行动作。

### 8.1 选题聚合规则

MVP 阶段先使用轻量规则聚合，不引入向量检索。

1. 时间窗口：默认聚合最近 7 天内容。
2. 关键词重合：标题或正文命中同一组核心关键词。
3. 来源优先：同主题内优先保留 S/A 级来源作为事实依据。
4. 标题相似：标题中核心名词高度重合时合并到同一选题。
5. 人工兜底：用户可以在文章池手动把文章加入已有选题。

聚合目标不是追求完全自动准确，而是减少重复选题，并把多篇资料汇总成一个可讲角度。

## 9. 栏目体系

### 9.1 AI效率快报

用途：讲最新 Agent 动态。

要求：不能只报新闻，必须回答“普通人接下来可以怎么用”。

### 9.2 一人工作流

用途：把 Agent 技术转成内容创作、资料整理、选题研究、脚本生成、代码辅助等流程。

### 9.3 Agent实战课

用途：拆解一个工具或一个真实任务。

示例：

1. 用 Codex 修改一个真实项目。
2. 用 Agent 做竞品资料整理。
3. 用浏览器 Agent 收集选题。

### 9.4 避坑诊断室

用途：讲常见错误。

示例：

1. 为什么你的 Agent 总是乱跑。
2. 为什么不能让 Agent 一次性改完整个项目。
3. 为什么自动化必须设置检查点。

### 9.5 前沿变白话

用途：解释 MCP、tool calling、memory、multi-agent、evaluation 等概念。

要求：每期至少给一个普通用户能理解的类比和一个可执行判断标准。

## 10. 脚本模板

### 10.1 热点解读模板

```text
开头钩子：
最近 AI Agent 圈有个变化，很多人会忽略。

一句话结论：
它真正影响的不是某个工具，而是你的工作流会不会被 AI 接管一部分。

误区：
千万不要只把它理解成一个新功能。

拆解：
第一，它改变了……
第二，它解决了……
第三，它带来了……

落地：
如果你是内容创作者/开发者/小团队，可以先这样用……

提醒：
注意，X 不是 Y。

结尾：
真正要学的不是追热点，而是看懂哪些任务已经适合交给 Agent。
```

### 10.2 工具教程模板

```text
如果你想用 AI Agent 完成一个真实任务，千万不要一上来就让它自由发挥。

正确方式是把任务拆成五件事：
目标、资料、工具、检查点、输出格式。

第一步……
第二步……
第三步……

你可以这样发给它：
「……」

注意，自动化不是无人看管，而是把人放在关键审批点。
```

### 10.3 观点拆解模板

```text
很多人以为 Agent 火，是因为模型更聪明了。

但真正的变化，是模型开始能连接工具、记住状态、执行多步骤任务。

判断一个产品是不是 Agent，不看它会不会聊天，而看它能不能完成闭环。

如果你是普通用户，你要先看三件事……
```

## 11. 页面设计

### 11.1 首页

展示：

1. 今日抓取数量。
2. 今日候选选题数量。
3. 高分选题 Top 10。
4. 待生成脚本数量。
5. 最近保存的脚本。

主要按钮：

1. 抓取今日内容。
2. 生成今日选题。
3. 进入选题库。

### 11.2 来源库

功能：

1. 新增信息源。
2. 编辑信息源。
3. 启用/停用信息源。
4. 手动抓取单个来源。
5. 查看最后抓取时间和错误信息。

### 11.3 文章池

功能：

1. 查看原始文章。
2. 搜索关键词。
3. 按来源、时间、语言筛选。
4. 标记无效内容。
5. 手动加入选题。

### 11.4 选题库

功能：

1. 按分数、时间、栏目筛选。
2. 查看内容卡。
3. 标记为“已选中”“已归档”。
4. 一键生成脚本。

### 11.5 选题详情

展示：

1. 内容卡完整信息。
2. 关联来源。
3. 关键事实和来源链接。
4. 风险提醒。
5. 推荐脚本方向。

### 11.6 脚本编辑页

功能：

1. 选择平台：抖音、小红书。
2. 选择时长：60 秒、90 秒、180 秒。
3. 选择栏目。
4. 生成脚本。
5. 编辑脚本。
6. 保存版本。
7. 生成标题、封面字、简介、话题标签。

### 11.7 设置页

功能：

1. 设置账号人设：名称、定位、目标受众、语气、内容边界、默认 CTA。
2. 设置 LLM 模型：provider、model、temperature、max_tokens。
3. 查看 API Key 配置状态，但不在页面显示或保存 API Key 明文。
4. 保存后，内容卡生成、选题评分、脚本生成都读取最新设置。

默认值：

```text
人设名称：AI效率教练
默认模型：从 .env 初始化，之后以页面设置为准
```

## 12. 发布素材包

每个脚本可生成：

1. 视频标题 5 个。
2. 封面文案 3 个。
3. 简介文案 1 个。
4. 话题标签 8-12 个。
5. 评论区引导问题 3 个。
6. 置顶评论 1 个。

说明：发布素材包在 V0.1 中不作为必需能力，优先级低于来源库、文章池、内容卡和脚本生成。V0.2 再做完整素材包生成。

## 13. 成功指标

### 13.1 产品指标

1. 每天生成可用选题不少于 5 个。
2. 单个脚本从选题到初稿少于 5 分钟。
3. 脚本人工修改比例低于 30%。
4. 每周稳定支持 5-10 条视频发布。

### 13.2 内容指标

1. 收藏率。
2. 完播率。
3. 评论率。
4. 关注转化率。
5. 评论区关键词：想试、求教程、看懂了、有用。
